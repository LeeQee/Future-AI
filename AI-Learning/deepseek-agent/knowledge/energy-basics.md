# 冷水系统 COP

冷水系统 COP 是衡量冷水系统能源利用效率的指标。
在明确统计边界后，通常以系统提供的制冷量
除以对应的系统输入功率计算。
计算时需要明确是否包含冷水机组、水泵和冷却塔等设备。
一般而言，相同工况和统计口径下，COP 越高，能效越好。

# COP 与 EER

COP 和 EER 都可用于描述制冷设备或系统的能源效率。
但在实际工程中，两者可能采用不同的定义、单位或统计边界。
进行比较前，应确认各指标的具体计算公式和适用对象。

# 牵引能耗

牵引能耗是轨道交通列车运行过程中，
牵引系统消耗的电能。
牵引能耗受到列车运行速度、载客量、
运行间隔、线路坡度和再生制动能量利用等因素影响。

# 动力照明能耗

动力照明能耗通常涉及车站照明、
通风空调、电扶梯、给排水等用电设备。
在地铁能源管理系统中，
动力照明与牵引用电通常需要分别统计。
